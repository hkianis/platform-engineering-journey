# Documentation

This directory stores durable engineering documentation produced during the roadmap.

## Planned Areas

- `architecture/` — architecture diagrams, design notes, and system-design exercises
- `learning-notes/` — concise notes that support implementation work
- `troubleshooting/` — reproducible failure scenarios and diagnostic write-ups
- `roadmap.md` — public engineering roadmap and progress status

Directories should be created when they contain a real artifact. Empty directory scaffolding is intentionally avoided.

## Documentation Standard

Documentation should answer at least one of these questions:

- What was built?
- Why was it designed this way?
- How was it validated?
- What failed and how was it diagnosed?
- What trade-offs or constraints matter?

Passive course notes without engineering application are low-value and should not dominate this repository.
